# 実験用リテリング・説得学習Webアプリケーション

学術実験プロトコル（画面1〜11、3モード切替、白黒ミニマルUI・メイリオ指定）に準拠したリテリング・説得学習システムです。

## セットアップ・新しいスプレッドシートIDの設定方法

1. `.env` ファイルを開き、新しく用意したスプレッドシートの ID を `VITE_SPREADSHEET_ID` に設定してください：
   ```env
   VITE_SPREADSHEET_ID=あなたの新しいスプレッドシートID
   ```
   （※ `VITE_GAS_WEBAPP_URL`、`VITE_GEMINI_API_KEY`、`VITE_DRIVE_FOLDER_ID` は既存プロジェクトの設定を引き継いでいます）
2. GAS 側で `mode`（実験モード）列および `rereadingSec`（再読解所要時間）列も保存したい場合は、`gas/Code.js` の内容を Apps Script エディタに貼り付けて「新しいデプロイ」（またはデプロイの管理から新バージョンへ更新）を行ってください。

## 起動・ビルド

```powershell
npm run dev     # 開発サーバー起動
npm run build   # 本番ビルド検証
```

## 画面遷移（画面1〜11）

1. **画面1（エントリー）**: 被験者ID（半角英数字）＋実験モード（モード1〜3）選択 → `saveInitial`
2. **画面2（お題提示）**: モード1は「自然やアクティビティが好きな人」、モード2・3は「完全なインドア派で虫や汚れが苦手な人」にキャンプの魅力を伝えるお題を提示
3. **画面3（カード選択）**: Card A〜D（各約70語・PREP法）から1枚選択
4. **画面4（読解フェーズ1）**: 選択カードの英文表示・読解時間計測 → `logReading`
5. **画面5（内容理解クイズ）**: 選択カードに対応する4択クイズ2問
6. **画面6（答え合わせ・解説）**: 得点（○ / 2点）・正誤・解説表示 → `saveQuiz`（再挑戦なし、そのまま次へ）
7. **画面7（再読解フェーズ2）**: 選択カードの英文再表示・滞在時間計測 → `logRereading`
8. **画面8（キーワード抽出）**: 左カラムに英文表示、右カラムに5つの単語入力枠（1枠1単語バリデーション）
9. **画面9（リテリング）**:
   - **モード2（独話型）**: アイコン＋デジタルタイマー＋録音操作（スタート／一時停止／リセット／終了して次へ）
   - **モード1・3（対話型）**: 既存のチャット・音声対話UIを流用
10. **画面10（評価画面）**:
    - **モード1**: 右側のCAF評価のみ表示
    - **モード2・3**: フル評価（キャラクター評価＋CAF評価）を表示
11. **画面11（実験終了・データ保存）**: `saveFinalAssessment` を実行し終了メッセージを表示
